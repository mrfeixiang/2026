The code

这段代码在做什么

T 恤背面是一段可运行的 Bash：eval "$(base64 -d <<< '…')"。外层把 payload 编成 Base64（像把剧本锁进信封），解码后立刻执行——这是运维里常见的打包手法，也是黑客文化里「一眼看不透、一跑就明白」的彩蛋写法。

解码后的脚本用 tput 读终端宽高、隐藏光标；用 bc 算正弦，让字符沿波浪横向摆动；再用 256 色 ANSI 从青（12）渐变到橙（208），无限循环画出 ♥PEACE♥FOR♥ALL♥…。Ctrl+C 会恢复光标后干净退出。橙色高亮字母按阅读顺序拼出口号本身——代码既是程序，也是可读的图形设计。

Akamai × Uniqlo

公司与公益项目

Akamai Technologies 是总部位于美国马萨诸塞州剑桥的网络安全与云公司，二十多年前以 CDN 加速奠定了今日互联网的基础设施。2025 年，它再次与 UNIQLO 合作，把设计放进慈善系列 PEACE FOR ALL。

据 Akamai 新闻稿：米色呼应早期电脑的「beige box」机箱；正面花括号里的心象征互联网被用于善意；背面是真实可跑的 Linux/Bash 代码——开源语言把工程师、品牌与用户连在同一愿景里。PEACE FOR ALL 自 2022 年启动，利润捐赠 UNHCR、Plan International、Save the Children 等机构；截至 2025 年 1 月已售出逾 660 万件、募得超过 1280 万美元。

相近的艺术脉络

把可执行源码印上服装，属于「code as fashion / wearable source」：程序不是说明书附图，而是视觉主体。它和 BBS 时代的 ANSI / ASCII art、欧洲 demoscene 的终端特效、以及 IOCCC（混乱 C 代码大赛）里「故意难读却优美」的美学同一谱系——混淆不是为了恶意，而是为了惊奇。

再往外，可以连到 net.art 与 glitch 美学（如 Jodi 把浏览器界面拆成材质）、代码诗（code poetry）、以及 GitHub / 开发者大会周边上常见的「把仓库印在胸口」。Akamai 这件 Tee 的特别之处在于：街上随手买到的衣服，真的能在终端里跑出一句和平口号——零售货架遇见了黑客彩蛋。
